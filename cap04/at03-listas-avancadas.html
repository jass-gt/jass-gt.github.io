2. Ranking de Tecnologias

  1. HTML

    Linguagem de marcação responsável pela estrutura de páginas web.

  2. CSS

    Tecnologia utilizada para definir estilos, cores e layouts.

  3. JavaScript

    Linguagem de programação que permite criar interatividade nas páginas.

  4. APIs Web

    Permitem a comunicação entre sistemas e aplicações distintas.

  5. React

    Biblioteca amplamente utilizada para construção de interfaces modernas.

3. Glossário de Termos Técnicos

HTML
Linguagem de marcação utilizada para estruturar páginas web.
CSS
Linguagem utilizada para estilização de páginas web.
JavaScript
Linguagem de programação voltada para interatividade na Web.
Pode ser executada tanto no navegador quanto no servidor.
DOM
Representação em árvore dos elementos de uma página HTML.
API
Conjunto de regras que permite a comunicação entre sistemas.
Pode disponibilizar dados ou funcionalidades para outras aplicações.
HTTP
Protocolo utilizado para transferência de dados na Web.
URL
Endereço Web
Localização única de um recurso disponível na Internet.
DNS
Sistema de Nomes de Domínio
Serviço responsável por traduzir nomes de domínio em endereços IP.
